# CHANGELOG

## [1.0.0] - 2026-09-07

### Added
- Initial release of iOS Admin Utility
- **TroubleshootingManager**: System diagnostics and health monitoring
  - Memory health checks
  - Storage capacity analysis
  - Battery status monitoring
  - Network connectivity checks
  - System permissions auditing
- **ResetManager**: Device reset operations
  - Soft reset functionality
  - Hard reset scheduling
  - Network settings reset
  - Full settings reset
  - Keyboard dictionary reset
  - Operation history tracking
- **EraseManager**: Data erasure and cleanup
  - Cache cleanup
  - Temporary file deletion
  - App-specific data removal
  - Selective data erasure
  - Device wipe capability
  - Storage space calculation
- **AccessManager**: Permission and access control
  - Permission request/grant/revoke
  - Access session management
  - Permission status tracking
  - User session logging
  - Multi-app permission control
- **DevelopmentToolsManager**: Debugging and development utilities
  - Device information retrieval
  - Multi-level debug logging (verbose to error)
  - Performance metrics monitoring
  - Log export in JSON format
  - Simulator detection
  - CPU and memory information

### Documentation
- Comprehensive README with feature overview
- Quick start guide with code examples
- Detailed API reference
- Complete examples documentation
- Security considerations and best practices

### Project Structure
- Swift Package Manager configuration
- Modular architecture with separate managers
- Well-documented source code
- Organized file structure
